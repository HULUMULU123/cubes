# Dice Table

Небольшая React/TypeScript игра: на деревянном столе можно бросать разноцветные кубики разных типов при помощи @3d-dice/dice-box и styled-components.

## Запуск
1. Установите зависимости: `npm install`
2. Запустите dev-сервер: `npm run dev`
3. Откройте выданный адрес (обычно `http://localhost:5173`).

В контролах можно менять тип кубика, количество, цвет и масштаб. История бросков сохраняет последние результаты.
